# 0010 Licensing

LANLink is MIT OR Apache-2.0. Dependencies are permissive (MIT, Apache-2.0,
BSD, ISC; `ring` is ISC with OpenSSL-derived parts). No GPL code is included:
Sunshine and Moonlight (GPL-3.0) were read for ideas only. The NVIDIA Video
Codec SDK is not used. ZXing and zxing-android-embedded are Apache-2.0. A
dependency licence report is generated at release (`docs/release.md`).
